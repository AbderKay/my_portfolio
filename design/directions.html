03 · Motion & interaction stack

You asked for GSAP used extensively. My senior recommendation is a two-engine setup — each doing what it's best at — rather than replacing what already works.

  • Lenis — buttery smooth-scroll. This is the single biggest “premium feel” unlock; it's the secret behind most Awwwards sites.
  • GSAP + ScrollTrigger — scroll storytelling: pinned sections, parallax, text/line reveals, timeline draw-in, image reveals, magnetic buttons.
  • Framer Motion — kept for React state animation: theme toggle, project filter, mobile menu, layout shifts (it's declarative and already wired).
  • Hero neural field — SVG/Canvas particle-graph with mouse parallax (not Three.js by default — 90% of the wow at a fraction of the cost; Three.js only if you want true 3D).
  • Guardrails — everything honors prefers-reduced-motion, throttles on mobile, and targets 60fps (transform/opacity only).
